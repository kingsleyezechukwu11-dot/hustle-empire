Hustle Empire is the user's game: an endless 3D Lagos city. Repo `kingsleyezechukwu11-dot/hustle-empire`, cloned to `Desktop/Claude Project/hustle-empire` (2026-11-17).

- The **browser game** is `street_src/` (Three.js r187, one big `main.js`). The Flutter app (`lib/`, `ios/`, `android/`) just shows it in a web view. User wants to work on the browser game only, not mobile.
- Build: `sh rebuild_preview.sh <preview-folder>` bundles to `assets/street/index.html` (esbuild + three live in `street_src/node_modules`, git-ignored).
- **Preview quirk:** the app's preview server cannot read the Desktop (macOS privacy), so the `hustle-street` launch config serves a *copy* of the built file from a session scratchpad folder. In a new session, point that config at a fresh non-Desktop folder and copy the build there. Reload with a new `?v=N` to dodge cache; `#dbg` exposes `window.__dbg` (hero, look, renderer).
- Goal for the look: GTA-style / clean avenue references (palms, skyline, puddles, long shadows). Done so far: real shadows on computers (phones keep cheap ones), Poly Haven photo sky + brick/plaster/asphalt/paving textures (CC0, `street_src/textures/CREDITS.txt`), reflective windows, glass shopfronts, striped awnings.
- User's question to build toward: "how do we make this game addictive" — suggested first step is one hustle job + cash counter + first upgrade. Not built yet.

**Why:** the user returns to this across sessions and earlier chat history was lost once.
**How to apply:** verify paths still exist; ask before committing/pushing (nothing from the look work was committed as of 2026-11-17). Related: [[linkedin-showcase-goal]].
